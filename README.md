# Una constelación hecha para ti ✦

Una experiencia romántica e interactiva creada únicamente con HTML, CSS y JavaScript. La persona que recibe el detalle debe descubrir cinco estrellas antes de revelar una constelación en forma de corazón.

## Personalización

Abre `script.js` y modifica el objeto `CONFIG` que aparece al inicio. Desde allí puedes cambiar:

- El nombre de la persona.
- Las dos iniciales.
- La invitación.
- Los cinco mensajes de las estrellas.
- El mensaje final.
- La ruta de la música.

## Música opcional

Coloca una pista que tengas permiso de utilizar en `assets/music.mp3`. Si el archivo no existe, el sitio funciona normalmente y oculta el control de música.

## Abrir el proyecto

Puedes abrir `index.html` directamente en el navegador. Para trabajar con recarga local, también puedes usar cualquier servidor estático sencillo.

## Accesibilidad

Las estrellas y botones funcionan con ratón, pantalla táctil y teclado. El diseño también respeta la preferencia del sistema para reducir el movimiento.
